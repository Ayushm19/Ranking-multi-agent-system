Smart processing

PII redaction, injection defence, and bias screens run before any model call. High-severity resumes are rejected; the batch continues.

6 guardrail layers

Evidence reports

Every quote is matched against the source resume. Unverifiable claims lower the score and can trigger human review.

Groundedness checks

Agent pipeline

Seven specialists fan out in parallel, then fan in through a verifier and critic before deterministic scoring.

Fan-out · fan-in

Eval harness

Golden-set NDCG, self-consistency across repeats, and an independent LLM judge so “did it get better?” has an answer.

NDCG · judge · consistency

API first
